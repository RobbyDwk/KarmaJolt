# KarmaJolt

Fault-Tolerant architecture enables real-time data processing and auto-scaling for optimized system and resource manager performance.

KarmaJolt is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Fault-Tolerant architecture enables real-time data
- processing and auto-scaling for optimized
- system and resource manager performance

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/KarmaJolt.git`
2. `cd KarmaJolt`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
